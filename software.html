Software Projects

Software Projects

ChronoXtract

ChronoXtract is a powerful library designed to extract features from your time series/sequential data.

HSC Image Tool

This tool retrieves bulk RGB images from HSC. It is a fork of the official PD3 data access tool, enhanced with multi-threaded support to drastically speed up image generation—especially when processing large datasets.

SDSS FITS Cutout Tool

This tool downloads a FITS image from the SDSS survey using SIAP, extracts an image cutout centered on given RA and Dec coordinates, and saves the cutout as a new FITS file.

DREX

DREX (Daily ArXiv EXplorer) is a Python-based command-line tool that allows users to fetch and display the latest research papers from arXiv.org based on specified categories.

NeurInk

NeurInk is a Python library that helps you generate high quality (publication-ready) diagrams for your neural networks. The tool is heavily under development.

RefForge

RefForge is a modern reference management tool that streamlines the process of collecting, organizing, and citing research papers. The tool is heavily under development.

DecidRX_py

DecidRX is a lightweight terminal-first decision engine that tells you what to do right now. It ranks your tasks based on deadlines, effort, reward and penalty so you can reduce decision fatigue and get daily wins.

EffDim

EffDim is a unified, research-oriented Python library designed to compute "effective dimensionality" (ED) across diverse data modalities. It aims to standardize the fragmented landscape of ED metrics found in statistics, physics, information theory, and machine learning into a single, cohesive interface.
